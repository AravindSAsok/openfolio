# Roadmap

## MVP implementation

- GitHub OAuth identity.
- Public profile and public repository synchronization.
- Dashboard profile and portfolio editor.
- Projects, skills, experience, education, certifications, and social links.
- Three free themes.
- Public /@username portfolio pages with server-rendered metadata.
- Manual and daily scheduled synchronization.
- D1 persistence and optional R2 upload endpoint.
- JSON export and account deletion.
- CI workflow and Cloudflare deployment instructions.

## Next improvements

- Browser end-to-end testing with a dedicated GitHub test account.
- Better synchronization batching and concurrent-run leases.
- Dashboard controls for image upload and image replacement.
- Custom domain support.
- Privacy-friendly page views.
- Additional themes and localized UI.
- Optional retrieval assistant with bring-your-own-key support.

Core portfolio creation and publishing remain free. AI and third-party analytics remain optional.
